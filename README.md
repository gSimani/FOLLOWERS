# Host Information Display

A simple web application that displays host and connection information in real-time.

## Features
- Real-time host information
- Connection speed testing
- Network status monitoring
- Automatic updates every 10 seconds

## Local Development
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000` in your browser

## Production Deployment
The application is automatically deployed to Vercel through GitHub integration.
